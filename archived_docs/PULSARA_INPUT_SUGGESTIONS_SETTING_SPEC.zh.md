# 输入框建议开关与用户口吻

状态：当前实施规格，2026-10-26。范围来自本次用户要求；已归档的临时请求规格只提供既有行为背景。

## 产品与归属

“设置 → 模型”中，模型配置卡片下方新增独立的“输入框建议”卡片。沿用模型配置、记忆检索的 header：左侧图标、标题和说明，右侧 toggle。说明为“回答结束后，使用当前模型生成下一条提问建议。”保存中禁用，失败保留已确认值并提示。

设置属于用户级 LocalSettingsStore，与活动会话及数据库是否就绪无关。`input_suggestions_enabled` 为可选布尔配置，未设置时默认为 true；写入时总是保存显式值，非布尔拒绝。沿用同一设置文档、读写 owner 与原子发布机制，不新增存储或迁移路径。发布失败不修改已安装的会话前缀。

## 请求和失效

- 仅在符合既有资格的用户执行链最终回答完成后，通过统一临时请求执行器生成建议。主 SYSTEM、tools 和已安装 messages 前缀保持不变，仅在临时分支追加指令。
- 关闭后，完成回调不启动建议；准备与结果采用时再次检查当前设置。所有现存 Host 的 pending/ready 建议失效，取消正在运行的请求；即使 provider 在取消后返回也不能采用。
- 保留运行中执行链的 admission 信息，以免影响自动标题。重新开启不为已经完成的轮次补发请求；随后符合资格的完成事件正常生成。
- 关闭时前端清理各会话的建议缓存、停止建议轮询并隐藏 placeholder；迟到读取及重新开启不能复活旧缓存。标题观察保留。
- 配置读取失败时放弃建议，不使正式回答失败。不引入 durable event、subject、guard、relation、job 或生命周期总上限。

## 提示词

保留从完整对话发现有依据的未解决问题、尊重既定决策、已解决时输出空文本的要求。明确假设自己是用户，第一人称指用户，第二人称指助手；不得以助手口吻提供帮助或反问用户偏好。加入自主决策边界、有限学习时间两个用户提问示例，标明仅示范口吻和格式，不能照搬主题。只输出一行问题，不调用工具。
