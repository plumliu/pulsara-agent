# 本机用户头像

状态：已实现并验证，已归档。2026-10-12。

- 入口为设置 → 通用 → 外观，紧凑一行，头像预览、上传/替换、恢复默认。
- 选图后打开原生模态裁剪框，`react-easy-crop` 6.2.4 负责固定 1:1、拖动、触摸/键盘及 1–3 倍缩放和有效裁剪范围计算，采用依赖的默认缩放范围。仅取消/保存两个按钮，不新增旋转或比例选项。依赖样式静态引入，弹窗不使用缩放入场动画，确保初始尺寸计算稳定。
- 浏览器 `createImageBitmap` 解码方向和动画首帧；原尺寸 PNG 预览与导出共享冻结像素。Pulsara 只将依赖返回的源像素范围通过 Canvas 导出为 256×256 PNG，并经现有头像接口保存。选图和取消不发上传请求，保存失败保留旧头像并允许重试。关闭释放 Blob URL 和 bitmap，异步解码晚于关闭时同样释放；裁剪状态不持久化。
- 当前 Pulsara home 的 `avatar.webp` 是唯一保存位置，使用现有 home 解析器；不修改设置 YAML、数据库或 provider 输入。
- Pillow 负责解码、EXIF 方向、居中裁切、缩放至 256×256 及 WebP 编码。支持 PNG/JPEG/WebP/GIF，动画取首帧，去除原始元数据。复用 HTTP 单次上传 8 MiB 上限与 Pillow 默认像素边界，限制一次图片处理的内存；不新增历史或总量上限。
- 后端先完整处理，再通过同目录临时文件原子替换；无效上传保留旧头像。删除文件恢复默认。仅一个文件，无版本历史、索引或新持久事件。
- 头像 HTTP 接口复用当前 loopback Host/Origin/关闭检查，无需数据库或会话控制权。图片与状态禁用缓存；同窗口替换立即更新，其他窗口重新聚焦时刷新。
- 设置页本机用户、侧边栏、主会话真实用户消息共用同一头像组件；过去用户消息随当前头像变化。默认使用同一用户图标。
- 子代理任务对话及继承任务记录中的主 Agent 输入使用独立机器人预设。定时任务输入使用同类中性预设。不凭显示名称判断发送来源。
- 验证自定义 home、上传替换删除、坏图片保留旧文件、编码尺寸与元数据、HTTP 访问边界，以及三处同步和消息来源隔离。用户自行检查界面，不要求真实浏览器 dogfood。

验证记录：头像图片/HTTP 7 项、既有本地 HTTP 17 项通过；前端头像与裁剪、设置、导航 21 项，子代理任务独立运行 18 项，以及会话发送者回归 1 项通过。裁剪覆盖固定比例和缩放参数、像素范围导出、取消不上传、关闭后异步解码清理、坏图与保存失败。TypeScript、定向 ESLint、Ruff、diff 检查和本地前端构建通过。子代理任务测试曾在并行运行中出现一次既有异步断言时序失败，独立运行通过，未更改该测试。应用会话回归使用 `NODE_OPTIONS=--no-experimental-webstorage`，避免当前 Node 的实验性 localStorage 覆盖 jsdom；不修改产品代码或测试断言规避该环境问题。
