# 连续对话阅读与历史驻留合同（冻结）

2026-10-22。用户明确要求：普通用户看到的对话中间不得断开，分页只能发生在当前阅读内容的顶部或底部。本合同取代历史文档中将 viewport 与独立 tail 窗口同时拼进主时间线的行为。主 agent 与 GPT-6 Astra（high）交叉审查同意后实施。

## 产品行为

- 主时间线始终只显示一个实际连续的 canonical 阅读区间。内部保留的其他窗口、最新执行草稿和工具结果不能跨越缺口拼接进来。
- 从顶部读更早内容，从底部读后续内容；旧区间的底部不是最新位置。回到最新显式切换到最新区间。
- 搜索、注释、来源定位成功后整体切换阅读区间；失败/取消保持原区间。迟到的导航和旧 DOM 驻留报告不能夺回阅读位置。
- 当前执行、停止和交互权限继续使用实时 owner。旧阅读区间中的当前待处理交互以独立状态面板呈现，不能伪装成历史的下一条消息。
- 真实历史缺口不伪装连续，不在中间显示“后续/中间记录尚未加载”两排内部术语。加载反馈仅在阅读区间边缘；错误可重试。

## 所有权与回收

- CanonicalHistoryReader 继续独占 entries/pages/context/cursors；Workbench 继续独占滚动、可见性、选择及焦点。Electron/后端/provider 输入不变，无持久事件、表或生命周期限制。
- 网络批次不是回收单位。将去重 canonical entries 排序，以当前区间内可见记录、选区、焦点和阅读锚点的连续凸包作为必须保留的阅读范围。
- 在凸包两侧各保留最多 128 条 / 2 MiB canonical 序列化数据作为可回读缓冲。沿用既有历史读取请求的物理预算尺度，限制每侧预留工作量，不限制总历史、整轮长度、单条合法内容或显式选区。字节计数按接纳时 entry 的 UTF-8 JSON 字节；后来补读的正文仍沿既有 supplemental body owner 回收。
- 最新尾部独立保留同预算后缀。后台正在读取、定位、未交接 live 和未配对 context 的保活不加入视觉阅读凸包。
- 保留与选定范围相交的完整原始页；原 page/context/paired cut 不合并、不伪造。允许页边界余量，不宣称 renderer heap 恒定或只有 2 MiB。
- 只从阅读区间两端退役，凸包中间不能删除。真实不连续区间只选择锚点所在的一段。尾部及其他保活区间留在内部，不决定当前视觉区间。
- 已有 tail 无完整 cut 时的回收等待，以及进行中 context 读取保活，继续遵守原协议；本次不增加并发、超时或生命周期上限，不宣称永久挂起读取时内存严格有界。
- 游标沿原 paired cut 回读；进行中的 page.read 与 cursor 对象身份保留。queue consumption/控制状态根据全部驻留 canonical 记录计算，不能因视觉隐藏而回退为待发送。

## 验收

- 相同 24 条记录一次/逐条/混合到达，短阅读区间都保持连续；超过缓冲后只从视觉两端回收。
- 可见或跨页选区凸包不挖洞；释放选择后能回收；长会话可向两端回读和重新定位。
- 旧位置持续收到新活动，主时间线不追加远端孤岛；旧区间滚到底仍可继续向后/回到最新。
- 定位/回最新失败、取消、互相抢占及晚到旧驻留报告均保持正确 owner；当前控制与队列消费不回退。
- compaction/interruption/工具关联/子任务嵌套活动遵守当前阅读区间，不跨缺口拼接。生产代码、回归测试与浏览器交互共同验证。

## 审计补充

- 成功导航以进程内对象身份标识当前阅读 owner。Workbench 的驻留报告携带该次 render 的 owner；同一连续区间内的旧 DOM 报告也不能覆盖新导航。失败/取消不替换 owner。
- canonicalInputs 仅为全部驻留输入的交接摘要（身份、来源、正文与分组状态），不复制正文或新增持久状态。屏幕外且分组已确认的输入允许释放可回读本地预览；当前展示区间仍等待正文就绪，防止气泡消失。
- 任务库存继续保留全部活动，嵌入主对话的活动再按阅读区间过滤。独立任务视图不受影响。
- 定位只补齐实际宿主的 sourceIds、展示上下文及展开所需推理；不能等待屏幕外正文的 IntersectionObserver 才完成导航。失败不切换阅读区间。
- 加载方向保留在原页请求 owner 上，向后加载的反馈和重试只出现在底部。

## 浏览器验收证据

实际 Chromium、生产 Workbench/reader 与隔离 HTTP 数据：初始 24 条；选中第 2 条后逐条增加 400 条，原选区及 scrollTop 保持不变，展示区间仍为单个连续区间（1–136）。滚至旧区间底部可继续向后阅读，并保留回到最新入口；回到最新后落在第 424 条。截图保存在 output/playwright/history-old-band.png、history-bottom-edge.png、history-latest.png。本次未调用真实模型或改写用户会话。
