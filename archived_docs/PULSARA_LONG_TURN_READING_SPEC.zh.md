# 超长 turn 的处理过程阅读合同

2026-10-22。用户授权；主 agent 与 GPT-6 Astra（high）交叉讨论后冻结。扩展 `archived_docs/PULSARA_CONTINUOUS_HISTORY_READING_SPEC.zh.md`，保留真实连续阅读区间，不引入折叠跨度中的 canonical 缺口。

## 用户行为

- 同一个执行 turn 只有一个处理过程入口；compact 是过程内部的时间线事件，不产生新的回复或折叠入口。不同 turn、真实阅读窗口及中断事实仍保留边界。
- 成功完成以实际 final 为准。仅完成转换发生时正在跟随最新、没有正在阅读的选区，才自动收起。停止执行本身不是成功完成。
- 未跟随最新时，完成不改变展开状态、阅读区间或位置；不得跳到远端 final。用户滚动或选择文字也能取消尚未完成的自动收起导航。
- 2026-10-22 用户测试补充：向上滚动（包括轻微/小数像素位移）、向上拖动滚动条立即退出跟随，不受底部距离影响。用户明确选择保留 20 CSS 像素的向下返回吸附范围，替代原先不区分方向的 80 像素判断；只有向下进入该范围或点击“回到最新”才重新跟随。原生滚动及几何变化由浏览器负责，Workbench 只管理跟随意图及阅读锚点，不拦截默认滚动。
- 手动收起/再次展开已完成的处理过程，仍读取该轮末尾的有界窗口；不记忆手动收起前的中段阅读位置。首次展开和再次展开从 final 附近开始，由顶部向前阅读。
- 2026-10-22 用户测试补充：展开维持答案附近的阅读定位；手动收起则保持点击的“处理过程”入口在屏幕上的位置，不能在读取末尾窗口后切换为答案锚点。入口 DOM 被阅读窗口替换时仍按同一过程身份恢复。若收起后的页面高度不足，接受浏览器滚动范围内的最近位置，不增加人为占位空白；自动完成收起仍按跟随最新规则处理。
- 后续用户要求双向抽屉过渡，当前动效以 `PULSARA_PROCESS_DRAWER_MOTION_SPEC.zh.md` 为准：展开与收起均连续改变高度，退出只短暂保留当前阅读窗口，动画结束卸载；不再平移整列。用户操作优先，迟到完成不能重新接管位置。
- 展开与收起的阅读切换成功后，先前内容只允许从整个可见时间线顶部或底部退役；视口按对应操作的锚点保持稳定。失败保留原内容及折叠状态，提供错误与重试机会。
- 来源定位仍打开准确的来源位置，不使用手动展开的末尾定位规则。
- 同一视觉插入位置的多个压缩成功事件显示一条分隔线及实际事件次数；相同 event ID 不重复计数。有正文或中断隔开的事件不合并；最终答案之后的压缩仍显示在答案之后。此规则不推断或改变压缩触发次数。

## 实现边界

- 后端继续拥有 canonical entry、context 和成对 cut/cursor。现有 `/window` 拥有 128 条 / 2 MiB 单次读取预算。前端 reader 选择实际连续的阅读区间；缓存相连不等于全部应当显示。
- 手动打开已完成过程即使 final 已缓存，也读取一个 final 附近的有界窗口；原子安装阅读区间，不能重新吞入整个相连缓存。沿现有分页向两端扩展、按可见凸包回收。
- 收起后不为隐藏过程创建逐条 React 折叠组件。折叠入口以实际 final（不可用时以当前可见片段）作锚点，不固定隐藏过程的首记录。
- 避免折叠入口与最终答案间的整个隐藏区间因凸包规则永久常驻：成功收起可将阅读区间切换到末尾窗口，顶部退役是本合同明确允许的行为。无新增历史长度、turn 长度或执行时长上限。
- 关闭的过程不会因滚动到顶部而反复自动下载隐藏记录。用户显式向前阅读时展开连续过程，再加载更早记录。
- context 的 final_entry_id 只能作为显式导航候选；旧 cut 可能携带更晚 final 的身份。不能仅凭此字段宣告已完成，导航必须核实实际 final。
- Workbench 继续拥有跟随、选区和滚动；复用现有读取/导航取消与 owner 身份。无新增持久事件、数据库、恢复机制或第二套 history reader。

## 验收

- 一个 turn 跨多页、多个 compact，只有一个过程入口；内部事件按时间排列。
- 跟随最新时 final 到达收起；中段阅读、选区或手动展开时保持过程和位置，final 在已退役远端也不抢占。
- 已缓存很长连续区间，重新展开仍只显示有界的末尾阅读窗口；逐页向上连续回读，加载及错误仅在边缘。
- 收起后的隐藏过程没有逐条 DOM/React 折叠壳；打开的渲染规模由阅读区间而非整轮长度决定。单条合法大内容仍沿既有正文/工具详情机制，不宣称绝对固定堆大小或零耗时。
- 展开/收起失败、取消、切换会话、来源定位抢占及迟到响应均不偷换阅读位置；旧 DOM 驻留报告无权覆盖新阅读 owner。
- 使用前端回归及真实浏览器验证布局、选择、滚动与长列表行为。
