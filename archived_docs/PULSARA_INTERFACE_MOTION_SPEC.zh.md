# 界面动态效果合同

2026-10-22。用户明确要求移除系统“减少动态效果”对 Pulsara 动画的限制。此合同替代历史规格中跟随系统减少动态效果的界面语义。

- Pulsara 没有独立的减少动态效果设置。旧代码通过浏览器的 `prefers-reduced-motion` 读取系统偏好；不修改用户的系统设置，也不新增应用开关。
- 界面始终使用已设计的动画和过渡时长，包括启动遮罩、通知出现/退出/重排、侧栏/抽屉/弹窗、折叠、批注、输入框移动、队列、悬停/焦点反馈、加载指示和授权完成页。删除全局压缩时长和局部禁用规则，不用反向覆盖或全局伪造媒体查询保留旧路径。
- 浏览器继续拥有动画执行、取消和布局。Pulsara 继续使用现有 CSS 与 Web Animations API；用户操作优先，结束/取消回调不能抢回已改变的阅读位置。隐藏页面暂停、组件卸载清理与无原生动画对象时完成收尾仍是正常生命周期行为。
- 交互可视化不再订阅系统动态效果变化，宿主环境 `reducedMotion` 固定为 `false`；主题和可见性继续实时传递。保留该字段的独立用途是静态截图采样，截图 worker 仍发送 `true` 取得稳定帧。这不是兼容旧系统设置的分支。
- 后续可视化创作指导不再按系统偏好禁用动画。既有用户 HTML/第三方网页不被改写；没有全局覆写浏览器 API。提示词与内置技能变更只沿既有冷 epoch / 显式采用的 compaction successor 安装，不重建已有 provider 输入前缀。
- 验证使用系统减少动态效果开启和关闭两种浏览器环境，检查 CSS 过渡/加载动画与通知生命周期一致；静态截图及页面隐藏暂停仍正常。

## 验证结果

移除 31 个前端 CSS 媒体查询块、1 个授权完成页媒体查询块，以及启动遮罩、通知、批注和输入框的 JavaScript 跳过分支。浏览器在 `reduce` 和 `no-preference` 两种环境下读取相同的折叠 220ms、批注 180ms、通知 220ms、设置开关 160ms 过渡，以及保持循环的加载指示；`reduce` 下折叠透明度逐帧从 0 到 1，未瞬时跳过。临时验证页面与浏览器会话已清理。

79 个前端文件、1232 项测试，31 项桌面测试，21 项授权回调及可视化相关 Python 测试通过；TypeScript 与变更前端代码 ESLint 检查通过。保留静态截图 worker 的独立采样语义；未调用真实模型或更改用户系统设置。
