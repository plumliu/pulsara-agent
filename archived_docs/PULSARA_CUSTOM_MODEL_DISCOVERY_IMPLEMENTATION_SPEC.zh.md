## 产品行为

自定义服务的 Model ID 使用可自由输入、按子串搜索、鼠标及键盘选择的下拉框。填写 Base URL 即可显式获取模型列表；不要求模型 ID、能力声明、协议或配置名称齐全。查询期间、失败、空列表或无匹配均可继续手填；保存和测试保留既有校验，独立于列表查询。

按草稿认证方式查询：Bearer 模式有新密钥则携带；编辑时仅同一规范化 endpoint 且原配置使用密钥认证才复用保存的密钥；否则匿名查询。无需认证模式始终不发 Authorization。匿名查询成功不改变实际模型调用的认证要求。地址或认证信息变化、关闭表单、页面卸载均使旧结果失效；取消前端请求并拒绝迟到结果。

## 所有权与边界

新增用户级 POST /api/model-configurations/discover，输入仅 base_url、authentication、api_key 及可选 connection_id，返回 model_ids。读取本机设置仅用于显式编辑目标的旧密钥解析；不依赖活动会话、数据库、models.dev 或模型运行时。查询不保存配置或候选列表，不发模型生成请求，不改变 provider input prefix、事件、subject、guard、relation 或 job。

OpenAI SDK models.list() 拥有 /models 路径拼接、HTTP 和响应解析；HTTPX2 拥有解压及关闭。Pulsara 复用现有 SDK client/凭据边界和检索 HTTP 的有界响应 hook（移到共享 SDK helper），只校验 data 中的非空原样 ID、去重并投影。列表不作为上下文、工具、图片、reasoning 或协议能力证明。原生 Anthropic/Gemini 协议不在本次范围；不猜测其他端点或自动追加版本。

这是一次用户触发的尽力查询，无自动重试；为避免一个列表操作无限占用资源，采用与现有连接探测相同的 10 秒连接/写入/连接池、30 秒读取空闲、45 秒总超时，以及已有 16 MiB 完整 provider 响应字节边界（解压后）。这是单次网络操作资源边界，不是模型数量或任务生命周期限制。使用 SDK 当前的非分页 OpenAI 模型列表契约，不静默截断条目。

所有成功、异常与取消路径关闭临时 SDK client。错误保留 HTTP 状态及有用的服务端详情，只精确隐藏实际密钥。列表返回密钥内容时拒绝采用该响应。保存的数据结构无需变更，删除自定义 Model ID 的纯文本框实现，替换为单一可编辑下拉框。
