# 处理过程双向抽屉动效

2026-10-22。用户要求展开和收起均使用抽屉动画。本规格替代此前收起时立即卸载、仅在滚动范围不足时平移整列的方案；保留超长 turn 阅读合同的其余语义。

## 行为与边界

- 展开与收起均使用 260ms 缓出高度过渡，文字保持清晰、不缩放、不交叉淡化。内容贴着抽屉底部裁切，先露出靠近最终答案的步骤，再向上露出更早内容。
- 展开继续按最终答案附近定位；手动收起尽量保持入口的屏幕位置。页面高度不足时接受浏览器的最近位置，随着抽屉高度变化连续移动，不增加空白占位，不叠加整列平移动画。
- 快速反向点击由浏览器从当前高度反向过渡。退出中的内容立即 inert，不可点击、选中或新发起正文读取；动画结束或取消后卸载。重新打开不能被旧退出回调卸载。
- 自动完成仅在跟随最新且无阅读选区时收起；中段阅读时不自动收起。来源定位、读取失败和取消、跨 compact 的单过程归属、末尾窗口读取均沿用现有规则。
- 每个连续可折叠区段复用一个现有 AnimatedDisclosure。用户补充与可视化保留原有可见性和时间顺序；不为隐藏的每一条记录保留动画壳。
- 动画只保留当前已驻留的阅读窗口，不额外加载整轮历史。过渡期间暂停基于视口的历史退役，结束后按当前会话与 reading owner 重新报告，旧会话的迟到回调无权报告新会话驻留。
- 不读取系统减少动态效果偏好。没有新增动画开关、时长上限、历史总量上限或持久状态。

## 归属

浏览器 CSS Grid 与原生过渡拥有插值、反向和布局；现有 AnimatedDisclosure 拥有懒挂载及退出清理；Workbench 拥有滚动锚点、跟随意图和驻留报告。底部裁切仅是过程抽屉的局部 CSS，不改变其他折叠组件。移除原 collapseMotion 整列平移路径。

## 验证

- 回归覆盖退出期间不读取隐藏正文、退出后卸载、快速重新打开后旧回调不卸载、用户补充和最终答案不被折叠、驻留报告延迟与会话切换隔离、受限滚动范围逐步变化。
- 隔离真实浏览器使用生产 Workbench 和 CSS，系统 reduced-motion 开启。6 步过程高度在 0 与 442px 之间逐帧单调变化，内容尾部始终与抽屉底部对齐，没有额外空白；128 步当前窗口在 0 与 9424px 之间过渡。收起中反向打开成功，最终收起后过程节点为 0。
- 测试使用隔离静态消息，无真实 provider 调用；不更改用户会话或系统设置。

最终验证：79 个前端测试文件、1234 项测试全部通过；TypeScript、变更生产代码 ESLint 和 diff 检查通过。首次全量运行有一项任务详情异步加载断言未及时观察到调用，未更改该断言或实现；该文件单独复测及随后完整复测均通过。临时浏览器 fixture、Vite 进程和浏览器会话已清理。
