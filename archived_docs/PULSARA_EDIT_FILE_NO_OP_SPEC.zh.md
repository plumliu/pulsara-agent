# edit_file 批量编辑中的无变化替换

状态：已实施，2026-09-28。

本规格取代历史行编辑规格中“单个 no-op 导致整批失败”的约定。

- `edit_file` 先校验完整批次：文件版本、已读取范围、行号、操作组合、重叠与换行格式规则保持不变。无变化替换不能绕过这些校验。
- 对通过校验的 `replace_lines`，若替换内容与原始 revision 对应行完全一致，静默跳过；同批其他有效修改正常应用，不额外返回警告。
- 行号始终基于原始 revision；前面的插入、删除或跳过操作不会移动后续锚点。
- `operations_applied` 只统计实际参与编辑的操作，不计跳过的替换。
- 最终编码后的字节与原文件完全一致时，整批返回 `NO_OP`，不执行写入；包括全部替换无变化、无变化的 `replace_file`，以及操作组合最终没有净变化的情况。
- 保留原子写入、写后校验、diff、revision 与已读窗口的现有路径；不新增存储或运行时事件。

验证：混合批次、原始行号、实际操作计数、全批无变化、校验失败不写入，以及已有文件编辑回归测试。
