# Pulsara {{version}}

这是 Pulsara 桌面预览版。可以在本机配置模型，使用会话、工具、Skills、MCP 和插件完成任务，并在工作台查看文件和交付结果。

## 本次更新

- 优化长会话阅读：展开多个处理过程后快速拖到顶部，仍会自动加载更早消息；复用已加载的短处理过程，减少展开等待。
- 处理过程保留首尾两个收起入口：顶部入口向上收起，底部入口向下收起；底部箭头显示当前展开状态。
- HTML 可视化由宿主管理离屏暂停与恢复，减少后台动画消耗；从内存卸载后重新打开会重新初始化页面。
- 统一“处理过程”文案，调整运行中工具卡片间距及正文分隔线留白；会话列表和“回到最新”显示运行状态，按钮增加交互动画，回到最新仍直接定位。
- 修复会话侧边栏记住收起状态后，进入页面重复播放收起动画的问题，并减少能力标签切换时的样式重算。
- 简化技能和 MCP 添加弹窗，支持选择本地技能目录；添加时提示当前目录作用域，并可跳转用户级能力页。补齐 MCP 导入弹窗的 Esc 关闭及保存期间保护。
- 记忆及记忆关系不再绑定创建它们的会话或工具结果；移除“在对话中查看”和“查看建立处”，保留记忆替代关系与写入校验。记忆列表更紧凑，并增加轻量过渡动画。
- 修复有关联关系的记忆无法删除、却被提示为“已不存在”的问题；保留删除影响确认、关联校验及旧记忆重新生效行为。
- 记忆页与定时任务页的操作结果和临时错误统一使用 toast；保留原有内容、草稿和重试入口。
- 定时任务页增加轻量内容与弹窗动画，展开和收起使用原生高度过渡，动画期间连续点击仍然有效。
- 用户消息和引导消息增加复制按钮；新建会话欢迎页不再显示“回到最新”。

## 安装

**macOS：**将 DMG 中的 Pulsara 拖入“应用程序”，推出 DMG，再从“应用程序”启动。此预览版没有 Apple Developer ID 分发签名，也未经过 Apple 公证；首次打开可能被拦截。确认下载来源后，先尝试打开应用，再到“系统设置 → 隐私与安全性 → 仍要打开”允许该应用。[Apple 官方说明](https://support.apple.com/zh-cn/102445)

配置有效模型连接即可开始使用。应用自带运行所需的 Python、数据库、浏览器和搜索工具，不要求预先安装 uv 或 Docker；具体任务需要的软件可在对话中按需准备。

## 数据与更新

配置、会话数据库及默认工作目录保存在 `~/.pulsara`；显式设置 `PULSARA_HOME` 时使用指定目录。卸载或替换应用不会主动删除这些用户数据。更新前请完全退出 Pulsara，再替换应用。开发构建和发行构建默认共用数据及 CLI，验收前请退出另一份应用。

**从 alpha.5 或更早版本升级：**本版删除了记忆来源关联字段，更新了数据库基线，不提供旧数据库的自动迁移。请先备份 Pulsara 数据；旧数据库不能直接沿用，保留历史需要另行迁移。请勿通过删除整个 `~/.pulsara` 来处理升级。

macOS 首次启动会注册 `~/.local/bin/pulsara`。已有其他来源的同名命令时不会自动覆盖，可在设置页查看和处理。
