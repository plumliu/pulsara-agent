# Pulsara {{version}}

这是 Pulsara 桌面预览版。可以在本机配置模型，使用会话、工具、Skills、MCP 和插件完成任务，并在工作台查看文件和交付结果。

## 本次更新

- 优化桌面启动、会话恢复和历史读取，减少重复读取及打开会话时的等待。
- 修复新会话开头从“准备开始”切换到处理状态时的布局跳变，以及从回复上下边缘拖选文字时不出现批注入口的问题。
- 长会话保持连续阅读，处理中间不再出现含义不明的未加载断层；跨多次上下文压缩的同一轮处理过程保持统一，并修复压缩分隔线重复显示。
- 阅读较早内容时，最终答案到达不再自动收起过程；重新展开从答案附近开始。轻微向上滚动即可脱离底部跟随，向下返回时保留 20 像素吸附范围。
- 处理过程采用双向抽屉动画，展开与收起平滑衔接，收起尽量保持入口位置；界面动画不再受系统“减少动态效果”偏好限制。
- “从目录中打开”默认定位桌面，桌面目录不可用时回到用户主目录；推理参数的提供方默认选项简化为“默认”。

## 安装

**macOS：**将 DMG 中的 Pulsara 拖入“应用程序”，推出 DMG，再从“应用程序”启动。此预览版没有 Apple Developer ID 分发签名，也未经过 Apple 公证；首次打开可能被拦截。确认下载来源后，先尝试打开应用，再到“系统设置 → 隐私与安全性 → 仍要打开”允许该应用。[Apple 官方说明](https://support.apple.com/zh-cn/102445)

配置有效模型连接即可开始使用。应用自带运行所需的 Python、数据库、浏览器和搜索工具，不要求预先安装 uv 或 Docker；具体任务需要的软件可在对话中按需准备。

## 数据与更新

配置、会话数据库及默认工作目录保存在 `~/.pulsara`；显式设置 `PULSARA_HOME` 时使用指定目录。卸载或替换应用不会主动删除这些用户数据。更新前请完全退出 Pulsara，再替换应用。开发构建和发行构建默认共用数据及 CLI，验收前请退出另一份应用。

macOS 首次启动会注册 `~/.local/bin/pulsara`。已有其他来源的同名命令时不会自动覆盖，可在设置页查看和处理。
